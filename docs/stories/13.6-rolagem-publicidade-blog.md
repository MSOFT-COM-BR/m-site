# 13.6 — Publicidade lateral acompanha a leitura do blog

## Escopo
Corrigir a rolagem dos dois anúncios laterais de artigos, sem mexer no carregamento de publicidade, slots, conteúdo ou outras rotas.

## Diagnóstico
Os wrappers tinham `is-sticky` e `position-relative` simultaneamente. A utilidade Bootstrap aplica `position: relative !important`, anulando a regra sticky existente. Removida somente a classe conflitante nas duas laterais, preservando a implementação CSS compartilhada.

## Aceitação
- [x] Ambas as laterais acompanham a leitura abaixo do cabeçalho (offset existente de 100px).
- [x] Os anúncios deixam de ficar presos ao atingir o fim do contêiner do artigo.
- [x] Laterais continuam ocultas no celular, sem overflow horizontal.
- [x] Mesmo comportamento nos temas claro/escuro, sem duplicar código.

## Evidências

Resultados em `/tmp/blog-ads-scroll-results.json`; screenshot inspecionado `/tmp/blog-ads-scroll-light-1440.png`.
