# Story 8.1: Menu horizontal com dropdown na área admin

## Story

- **Como:** Admin Master da Miranda Soft.
- **Quero:** que o painel `/admin` use um menu horizontal com dropdowns em vez da sidebar vertical.
- **Para que:** a navegação entre abas fique mais compacta, aproveite melhor a largura da tela e agrupe funções relacionadas.

## Contexto

O painel admin usa uma sidebar vertical (`col-md-3`) com 6 botões empilhados: Aparência (`theme`), MJSON (`mjson`), Mídia (`images`), Módulo Blog (`blog`), System Logs (`logs`) e Usuários (`users`). A área de conteúdo fica espremida em `col-md-9` e a navegação não agrupa funções relacionadas.

Decisões aprovadas pelo usuário:
- Agrupamento: **Aparência** | **Conteúdo ▾** (MJSON, Módulo Blog) | **Mídia** | **Sistema ▾** (System Logs, Usuários).
- Mobile: hamburger que abre painel com os grupos.
- Posição: abaixo do cabeçalho do painel, dentro do card.

## Acceptance Criteria

1. A sidebar vertical é substituída por uma barra de menu horizontal `.admin-nav` abaixo do cabeçalho do painel.
2. Itens diretos: Aparência (`theme`) e Mídia (`images`).
3. Dropdowns Bootstrap: Conteúdo (`mjson`, `blog`) e Sistema (`logs`, `users`).
4. Cada ação de navegação chama `loadTab(tab)` sem alterar a assinatura da função.
5. O estado ativo é refletido no item e no grupo pai (ex.: aba `blog` destaca o menu Conteúdo).
6. Persistência da última aba (`msoft_cms_last_tab`) continua funcionando e restaura o estado ativo correto.
7. Em viewport `<992px`, a barra colapsa em botão hamburger que abre painel com os mesmos grupos empilhados; seleção fecha o painel.
8. CSS morto `.cms-sidebar*` é removido; novo CSS `.admin-nav*` segue o tema zinc do painel.
9. Versão bumpada nos 3 lugares (`index.html`, `config.js`, query strings).
10. Nenhuma mudança em APIs, autenticação ou conteúdo das abas.
