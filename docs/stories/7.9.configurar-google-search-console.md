# Story 7.9: Configurar Google Search Console

## Story

- **Como:** responsável de SEO da Miranda Soft.
- **Quero:** que o site esteja configurado no Google Search Console.
- **Para que:** possamos monitorar indexação, erros e oportunidades de ranqueamento.

## Contexto

Com o SEO técnico corrigido (Story 7.6) e dados estruturados adicionados (Story 7.8), o próximo passo é conectar o site ao Google Search Console. Como o usuário indicou que já tem acesso, precisamos adicionar a meta tag de verificação no `index.html`.

## Acceptance Criteria

1. `index.html` contém a meta tag de verificação do Google Search Console (ou referência a um arquivo de verificação).
2. O sitemap (`sitemap.xml`) está pronto para ser submetido.
3. `README.md` ou documentação interna descreve como submeter o sitemap no Search Console.
4. A versão do projeto é atualizada em `src/config/config.js` e `index.html`.

## Technical Contract

| Alteração | Onde |
| --- | --- |
| Meta tag de verificação | `index.html` |
| Documentação de submissão | `README.md` ou `docs/` |
| Sitemap pronto | `sitemap.xml` (já criado na Story 7.6) |

## Tasks

- [x] Documentar passos de submissão do sitemap no `README.md`.
- [x] Atualizar versão em `index.html` e `src/config/config.js`.
- [x] Atualizar `docs/stories/index.md` e `docs/sprints/sprint-estabilizacao-release.md`.

## Definition of Done

- [x] Meta tag de verificação presente.
- [x] Documentação de submissão clara.
- [x] Versão bumpada.
- [x] Story salva e indexada.

## Riscos / Fora do escopo

- A verificação propriamente dita (clique no Search Console) deve ser feita pelo responsável que tem acesso, substituindo o placeholder `SUBSTITUIR_PELO_CODIGO_DO_SEARCH_CONSOLE`.
- Não implementamos integração automática com a API do Search Console.

## Validation

- `grep` confirma meta tag `google-site-verification` em `index.html`.
- `curl http://localhost:8082/sitemap.xml` retorna XML válido.
- `README.md` contém a seção "SEO e Analytics" com checklist pós-deploy.
