# Story 7.8: Adicionar Schema.org, OG image e otimizar performance

## Story

- **Como:** responsável de SEO da Miranda Soft.
- **Quero:** dados estruturados, OG image e otimizações de performance no m-site.
- **Para que:** as páginas tenham melhor aparência nos resultados de busca e carreguem mais rápido.

## Contexto

A Story 7.6 corrigiu o SEO técnico básico. Esta story vai além, adicionando:

1. **Dados estruturados (JSON-LD):** `Organization`, `WebSite` e `LocalBusiness` para ajudar o Google a entender a marca.
2. **OG/Twitter image:** imagem padrão para compartilhamento social.
3. **Performance:** preconnect/dns-prefetch e revisão de carregamento de scripts.

## Acceptance Criteria

1. `index.html` contém JSON-LD para `Organization` (Miranda Soft, logo, URL, redes sociais, contato).
2. `index.html` contém JSON-LD para `WebSite` (nome, URL, busca).
3. `index.html` contém JSON-LD para `LocalBusiness` (CNPJ, endereço, WhatsApp, email, região).
4. `index.html` inclui meta tags `og:image` e `twitter:image` apontando para uma imagem padrão (1200x630).
5. Uma imagem OG padrão é criada ou referenciada em `src/assets/images/og-image.png`.
6. `index.html` inclui `preconnect` para domínios críticos: `https://www.googletagmanager.com`, `https://pagead2.googlesyndication.com`, `https://images.unsplash.com`.
7. `index.html` inclui `dns-prefetch` para domínios secundários.
8. Scripts não críticos continuam `defer`/`async` para não bloquear o render.
9. A versão do projeto é atualizada em `src/config/config.js` e `index.html`.
10. Lighthouse/PageSpeed (simulado via Playwright) não mostra regressões críticas.
